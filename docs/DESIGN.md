## 1. 项目定位与目标用户

| 角色 | 使用场景 | 核心诉求 |
| --- | --- | --- |
| 长辈（主视角） | 每天面对吃药、亲友通话、出门、给孩子报平安四类高频事务 | 看得清、点得准、听得懂、做完有成就感 |
| 子女（守护视角） | 远程为父母设置提醒，确认父母是否按时吃药、是否平安 | 设置省力、可回头修改、动态可见、成果可纪念 |
| 评委（体验视角） | 30 秒内体验全部功能 | 顶部一键切换双端视角，首屏即有可点数据 |

设计主张：把**适老化实用功能**与**游戏化趣味正反馈**融合——备忘不再是清单，而是一座会因为坚持而开花的「亲情花园」。

## 2. 设计原则

### 2.1 适老化硬性指标（不可回退项）

1. 基础字号三档：**标准 20px / 大 22px / 特大 25px**，只改根字号，全站 rem 尺度（文字、内边距、圆角、间距）联动放大；档位选择持久化到本机，任何屏宽都不得低于 20px。
2. 标题层级随根字号缩放：标准档实测页面主标题 42px（2.1rem）、卡片标题 32px（1.6rem）、弹窗主标题 42px。
3. 所有可点击控件高度 **≥60px**，主操作按钮 72–80px；实测页面无一个按钮低于 60px。
4. 高对比暖色：底色 `#FFFDF7`、正文 `#222222`，对比度 ≈15.6:1（超 WCAG AAA）。弱化文字统一使用 `--ink-mute: #6B6552`，实测对最浅背景 `#FFF0C4` 为 5.2:1，达标 AA（旧值 `#8A8266` 仅 3.3:1，已废弃）。
5. 大圆角（14–42px）+ 宽间距（卡片间 26px、区块间 22px），按钮彼此隔离，防止误触。
6. 键盘与读屏可达：首屏 skip-link 直达卡片区、弹窗 Tab 焦点陷阱、关闭后焦点归还触发按钮、`aria-pressed` 状态同步、`:focus-visible` 4px 蓝色描边。

### 2.2 游戏化三原则

1. **即时反馈**：一次操作同时给视觉（印章+粒子）、听觉（音效+语音）、数值（能量+100）三路反馈。
2. **可视化成长**：抽象的坚持被换算成植物四阶段成长，进度条永远指向"下一个可见目标"。
3. **可纪念的成果**：年度战绩海报把日常打卡升华为"战绩"，勋章给出社交话题。

## 4. 视觉规范

### 4.1 配色体系

| 用途 | 类别主色 | 卡片底 | 卡片描边 | 正文 |
| --- | --- | --- | --- | --- |
| 全局背景 / 正文 | — | `#FFFDF7` | — | `#222222` |
| 分区容器（顶部 / 标签条 / 设置面板） | — | `--bg-soft #FBF6EA` | `--line #E6DCC6` 2px | — |
| 花园分区 | — | `--bg-garden #F4F9F3` | `--line` 2px | — |
| 所有卡片与弹窗 | — | `#FFFFFF` | 三边 `--line` 2px + **左侧 10px 类别色条** | `#222222` |
| 💊 按时吃药 | `#C25A00` | — | — | 仅色条 / 标签 / 选中态 |
| 📞 亲友电话 | `#0B6E9E` | — | — | 同上 |
| 🚌 出行提醒 | `#146B3A` | — | — | 同上 |
| 💌 给孩子的留言 | `#A8325C` | — | — | 同上 |
| 品牌与选中态 | `--accent #6B4E00` | — | — | 反白 `#FFF` |
| 完成态 / 印章 | `#146B3A` / `#C0392B` | 白 | — | 白 / 红 |
| 弱化文字 | `--ink-mute #6B6552` | — | — | 对白底 5.8:1，达 AAA |

规则：

1. 卡片正文一律 `#222222`（对白底 15.9:1），类别信息**只**通过「左侧 10px 色条 + 类别标签文字色 + 选中态填充」三处编码，不再使用淡彩底与彩色描边。
2. 全站已无 `linear-gradient` / `radial-gradient`：分区底、进度条、勋章边框全部为单一色值；强调靠色相而非高光。
3. 类别主色用作 23px 粗体标签文字时实测 4.42:1——按 WCAG 大号文本（≥18.5px 粗体）标准达 AA；若日后把该标签缩小到正文级，需改用更深的类别色。
4. 不使用 `opacity` 表达"次要"，一律改用色值（见 §2.1 第 4 条）。
5. 图形只用**一套内联 SVG 精灵**（`index.html` 顶部 `<symbol id="ic-*">`，HTML 与 JS 均通过 `<use href="#ic-*">` 引用）。形状只依赖两个变量：`currentColor`（跟随文字色，因此标签选中态"类别色底 + 白字"时图标自动反白）与 `--bloom`（花/果的第二色，仅花园主图与信封爱心使用）。图标一律 `aria-hidden="true" focusable="false"`，不参与读屏朗读。
6. 页面底色叠一层 5% 浓度的单色噪点 SVG（`body` 的 `background-image`，200×200 平铺）作纸纹；它不承载信息，也不与任何色值比较对比度。

### 4.2 降噪与质感规范（2026-11-17 起）

| 维度 | 收敛后的做法 |
| --- | --- |
| 色彩层次 | 一张卡片从「淡彩底 + 4px 彩边 + 大 emoji + 彩标签 + 白胶囊」五层，压到「白底 + 色条 + 彩标签 + 图标」 |
| 描边宽度 | 常规 2px（`--bw`）、触控控件 3px（`--bw-lg`）、卡片色条 10px（`--spine`）；旧的 4–5px 粗边全部下线 |
| 动画 | 仅保留一次性触发：`rise / slide-in / fade / bloom / stamp-drop / fall`；`sway`（植物摇摆）、`float-deco`（装饰飘动）、`shine`（进度条斜纹流光）、`spin`（海报光斑旋转）已删除。页面静止时唯一的持续动画是通话弹窗的振铃扩散环 `pulse` |
| 图形 | 类别图标、四阶段植物、品牌标记、分类筛选与卡片操作按钮全部改为 SVG 精灵；花园区原有的 emoji 装饰层（🌿🌼🦋🍎🍇）整体删除，避免同一画面里"手绘图形 + 系统 emoji"两种画风打架 |
| emoji | 只保留在**语义本身是表情/人脸**的位置：模式切换 👵🧑（两张脸差异比剪影更好认）、通话头像（按称呼匹配性别年龄）、勋章、撒花粒子。`听一听 / 我办妥了 / 一键呼叫` 三个高频按钮已换成 SVG 图标 + 纯文字 |
| 粒子 | 打卡全屏撒花 30 → 16 颗，按钮迸发 14 → 9 颗，升级补撒 24 → 14 颗；emoji 种类 8 → 4 |
| 阴影 | 双层叠加：`--shadow` = 1px 贴近 + 8px 20px 扩散（合计约 .05 + .06 透明度），`--shadow-lg` 用于浮层与悬停；选中态不再额外叠阴影 |

### 4.3 控件尺度（降噪前实测值，降噪后需重新复核）

| 控件 | 高度 | 字号 |
| --- | --- | --- |
| 卡片主按钮（听一听 / 我办妥了） | 72px | 25px |
| 一键呼叫按钮 | 80px | 28px |
| 模式切换按钮 | 67px | 22px |
| 分类标签 | 64–65px | 24px |
| 字号档位按钮 `.ts-btn` | ≥60px | 19px |
| 快捷短语 / 输入框 | 64px | 23px |
| 通用按钮 `.btn` | ≥60px | 23px |

> ⚠️ 上表是**降噪改造之前**的实测值。本次把卡片描边由 4px、控件描边由 3px 统一降到 2px：因为 `box-sizing: border-box`，凡由 `min-height` 下限决定的控件（72 / 80 / 64 / 60px）高度不变；而依赖文字撑高的控件（如模式切换按钮 67px）可能回落 1–2px，仍远高于 60px 红线，但**需在真实视口下重新实测一次**再确认（本轮内嵌浏览器面板视口宽度为 0，几何量测不可信，见 §8 同条记录的说明）。

> 尺度放大机制（实测校准）：三档字号放大的是 rem 部分——文字、内边距、圆角、间距；而各按钮的 `min-height` 写的是 px 固定下限（60–80px），**不会**随根字号缩放，实际高度靠放大后的文字撑高。实测「特大」档下一键呼叫按钮高 147px（下限仍是 80px）。因此"触控目标一定同步变大"并不严谨：单行短文字的按钮可能仍停在 px 下限。若要真正等比，应把 `min-height` 改为 rem（见 §9 待办）。

## 5. 数据设计

### 5.1 存储

- 唯一键：`localStorage['suisuinian.memo.v1']`
- 首次打开（无该键）自动写入 4 条示例卡片，覆盖四大分类，保证"点开即可体验"。
- 写入失败（隐私模式 / 存储被禁）时捕获异常并 toast 提示，不中断交互。

### 5.2 结构

```jsonc
{
  "day": "2026-11-16",              // 打卡日标记，用于隔日重置
  "mode": "elder",                  // elder | child，刷新后保持
  "textSize": "normal",             // normal | large | xlarge
  "energy": 560,
  "stats": { "childSetups": 1, "messages": 2 },
  "checkins": [                     // 打卡流水，年度战绩的数据源
    { "cardId": "c...", "type": "medicine", "at": "ISO", "heading": "氨氯地平 5 毫克" }
  ],
  "feed": [                         // 通知栏动态，最多保留 24 条
    { "kind": "checkin|message|setup", "text": "…", "at": "ISO" }
  ],
  "cards": [
    {
      "id": "c…", "type": "medicine|phone|travel|message",
      "source": "child|seed",
      "heading": "主标题（大字）",
      "line2": "副信息", "line3": "时间信息",
      "phone": "仅亲友电话",
      "done": false, "doneAt": null,
      "sent": ["仅留言卡：已发送的短语"]
    }
  ]
}
```

`line2` / `line3` 的展示语义随 `type` 变化，由 `CATS[type].rowLabels` 决定标签文字：

| type | heading | line2 | line3 | phone |
| --- | --- | --- | --- | — |
| medicine | 药名 | 剂量与叮嘱 | 提醒时间 | — |
| phone | 亲友 | 方便时间 | （右上角时间胶囊） | 号码 |
| travel | 目的地 | 随身带 | 出发时间 | — |
| message | 卡片标题 | — | 时间胶囊 | — |

> 已知取舍：用统一的 `line2/line3` 而非按类型分字段，换取渲染与存储的简单；后续若要按类型做校验或提醒时间调度，应拆成结构化字段（见 §9）。
> 加载时 `migrate()` 会补齐缺失字段并把非法 `textSize` 归位为 `normal`，旧版本数据可无损升级。

### 5.3 隔日重置规则

清空每张卡片的 `done/doneAt`（印章消失、按钮恢复可点），但 **`energy`、`checkins`、`feed`、`stats` 全部累计保留**。触发时机有三处，保证"页面整天开着也不会留旧印章"：

1. 加载时 `migrate()` 比对 `state.day`；
2. 每 30 秒轮询 `rolloverIfNewDay()`；
3. `visibilitychange`（标签页重新可见）与 `window focus` 时立即检查。

后两者命中时会重绘并 toast「新的一天，印章已清空」+ 语音播报。

### 5.4 跨标签页同步

监听 `window` 的 `storage` 事件：另一端（如子女模式标签页）写入后，本端重新读取状态并整体重绘，同时 toast「已同步另一端最新打卡动态」。演示方式：开两个标签页，一个长辈模式打卡，另一个子女模式的通知栏会实时冒出新动态。

## 6. 模块设计

### 6.1 双端视角一键切换

| | 👵 长辈卡片模式（默认） | 🧑 子女守护模式 |
| --- | --- | --- |
| 卡片按钮 | 仅 听一听 / 我办妥了（亲友电话多一行一键呼叫） | 仅 听一听（试听）+ 状态胶囊 + 修改这张 + 移除这张卡片 |
| 顶部 | 年度战绩报告 + 字号三档 | 年度战绩报告 + 给爸妈设置提醒 + 字号三档 |
| 通知栏 | 隐藏 | 显示，实时流水 |
| 快捷短语 | 可点选发送 | 只读禁用（防止子女代父母"报平安"，语义失真） |
| 切换反馈 | 语音播报"已切换到长辈卡片模式…" | toast 说明可做什么 |

实现要点：`body[data-mode]` 控制 `.only-child` / `.only-elder` 显隐，**只写 `display: none`，不覆盖元素自身的 flex/grid**。

### 6.2 四大场景卡片

卡片为**白底 + 左侧 10px 类别色条**，色条颜色即类别（见 §4.1）；卡片内部不再出现第二种色彩表达，正文一律 `#222222`。

- 💊 吃药：药名 / 剂量与叮嘱 / 提醒时间，附温水送服温情提示。
- 📞 电话：整行超大「一键呼叫 女儿」（左侧 SVG 话筒图标），弹窗内头像随姓名智能匹配（女儿→👩、儿子→👨、奶奶→👵…）。
- 🚌 出行：目的地 / 出发时间 / 随身带清单，附"出门前看看天气"提示。
- 💌 留言：6 句大字短语（"今天按时吃药啦，别惦记"等），点一下即发送，已发送项转为绿色 ✓ 状态，无需打字。
- 时间胶囊改为**透明底 + 2px 细线**描边，不再是白色实心胶囊。
- 顶部大标签一键筛选，`aria-pressed` 同步，筛选后计数文案随之变化；选中态用类别主色实心填充 + 白字（降噪后不再叠加阴影与加粗边框）。

### 6.3 🌱 亲情暖心花园

能量来源：打卡 **+100**、发送留言 **+60**。

| 阶段 | 能量区间 | 主图形（SVG 精灵） | 第二色 `--bloom` |
| --- | --- | --- | --- |
| 小嫩芽 | 0–299 | `#ic-sprout` 双叶嫩芽 | 不用（纯绿） |
| 含苞待放 | 300–799 | `#ic-bud` 花苞 | `#D9679B` |
| 繁花盛开 | 800–1599 | `#ic-blossom` 五瓣花 | `#F291B4` |
| 硕果累累 | 1600+ | `#ic-fruit` 结果树 | `#C0392B` |

原来的 emoji 装饰层（🌿 / 🌼🦋 / 🍎🍇）已整体删除：植物本体改成手绘 SVG 后，同一画面里再叠系统 emoji 会出现两种画风打架，且果实、花瓣已经画进主图形，装饰层不再承载信息。

- 进度条显示"当前阶段 → 下一阶段"的完成度，文案给出**还差多少点**的具体目标（封顶阶段改为成就文案）。

## 7. 技术选型与约束

| 决策 | 理由 |
| --- | --- |
| 三个静态文件、无构建 | 比赛要求"无需后端服务器即可在浏览器直接运行"，双击 `index.html` 即演示，零环境成本 |
| `js/app.js` 用单个 IIFE 传统脚本，**不用 ES Modules** | `file://` 协议下 `import` 受 CORS 限制会直接报错，传统脚本才能双击运行 |
| 目录仅按 `css/ js/ docs/` 分层 | 保持相对路径引用，不引入任何加载风险 |
| 字号三档只改根字号 | 一处改动驱动全站 rem 联动，避免维护两套尺寸表；触控目标随字号同步变大才是真适老 |
| 弱化文字用色变量 `--ink-mute` 而非透明度 | 叠加 `opacity` 会把对比度拉到 AA 以下，改色值才可控 |
| 语音用 `speechSynthesis`、音效用 WebAudio | 均为浏览器原生能力，不联网、不下载、不上传任何信息 |
| 定时器统一登记（`callTimers` / `callIntervals`） | 通话弹窗可反复打开/挂断，必须保证旧定时器全部清理，否则计时错乱 |
| 跨日检查用「加载 + 30s 轮询 + 可见性/聚焦」三重触发 | 长辈设备可能整天不刷新页面，只靠加载判断会留着一天的旧印章 |
| 尊重 `prefers-reduced-motion` | 该偏好下跳过粒子动画与平滑滚动，动效敏感长辈也能安全使用 |
| 无框架、无第三方库 | 代码体量可控，评委可直接读源码理解实现 |
| 视觉降噪也**不**引入 CSS 框架 | 部署上线只解决了"CDN 需要联网"这一条，另外两条仍在：本次是删除性改动（去渐变、去常驻动画、压色彩层次），框架只提供增量；Tailwind Play CDN 官方标注不宜用于生产，且浏览器内即时编译会给首屏加一次 JS 执行。真要用 Tailwind 就得本地 build 后提交产物，等价于"仓库里一份静态 CSS"，运行时仍是零依赖 |
| 协作者的三档字号机制优先于框架默认尺度 | `html[data-textsize]` 只改根字号即可让全站 rem 联动；框架自带的设计尺度表会与之争夺控制权，迁移中极易把"特大档"退回固定 px，丢掉硬指标 |
| 配色与尺度固化为 `:root` token 表（§4.1） | 想要的其实是框架的"一致性"，而 token 表能在零依赖前提下给到：改一个变量即可全站收敛，不需要引入任何文件 |
| 图形用**单个内联 SVG 精灵**，不引图标库、不用外部 `.svg` 文件 | 零依赖与 `file://` 双击可运行是硬约束：图标库要么联网要么进构建；外链 `.svg` 在 `file://` 下 `<use>` 会被 CORS 拦。同文档内的 `<use href="#id">` 不受限，且形状用 `currentColor` 绘制，选中态反白不用二次描图 |
| 纸纹用 data-URI 单色噪点，不用位图素材 | 一张 200×200 平铺，不增加文件、不产生网络请求，也不会像照片纹理那样压过文字对比度 |

### 2026-11-17 · 图形质感升级：emoji 换成内联 SVG 精灵 + 纸纹与双层阴影

  3. 引用方式统一：HTML 写 `<svg class="ic"><use href="#ic-…"/></svg>`，JS 加 `icon(id, cls)` 与 `iconBtn(cls, id, text)` 两个小工厂（`createElementNS` 建 svg/use，一律 `aria-hidden="true" focusable="false"`）。配置表由 `emoji` 字段改为 `icon` 字段（`CATS`、`STAGES`）。

## 9. 已知限制与后续候选

**当前限制（答辩时需如实说明）**

1. 「远程为父母添加卡片」在无后端前提下是**同浏览器双视角**演示；真实跨设备同步需要账号与消息通道。
2. 模拟通话不实际拨号，仅动画 + 音效 + 语音提示。
3. 语音音色依赖操作系统内置 TTS；若系统缺少中文语音包，可能静音（已做不支持时的文字降级）。
4. 卡片没有到点提醒能力（无 `Notification` / 定时调度），当前是"打开即见"的备忘形态。
5. 「特大」档（25px 根字号）下长文案卡片会变高，尚未逐条排版复核。
6. 无自动化测试，质量保障依赖手工走查清单。

**后续候选（等需求确认后再实施，不提前动代码）**

- ⚠️ **控件高度需在真实视口下重测**（降噪后首项）：描边由卡片 4px / 控件 3px 降到 2px / 3px 后，§4.3 表中的高度需重新采集一次；本轮内嵌浏览器面板 `window.innerWidth === 0`，几何量测不可信。
- 把各按钮的 `min-height` 由 px 改为 rem（如 `.act` 3.6rem、`.btn` 3rem），让「大 / 特大」档真正等比放大触控目标，而不是只靠文字撑高。
- `.skip-link` 加 `white-space: nowrap`，解决极窄视口下被挤成竖排窄条（详见 §8 的 2026-11-16 待观察项）。
- 按类型拆分结构化字段（如 `medicine.dose/time`），支持字段校验与提醒时间调度。
- 接入 `Notification` API + 到点检查，实现真正的定时提醒（仍保持纯前端）。
- 留言支持录音回放与语音转文字，进一步降低打字门槛。
- 花园增加"连续坚持天数" streak 与枯萎/浇水隐喻，强化长期动机。
- 导出年度战绩图片（Canvas 绘制）替代截图/PDF。
- 三档字号下的排版复核与回归清单（尤其长药名、多携带物品、特大档 + 窄屏叠加时）。
- 类别标签若需缩小字号或减重，先换更深的类别主色再调（当前 4.42:1 只在 23px/800 下满足 WCAG 大号文本 AA）。
- 画风统一收尾：勋章、通话头像、撒花粒子目前仍是 emoji（语义本身是"人脸 / 表情 / 庆祝物"，见 §4.2）。若评委或用户仍觉得不统一，可为这三类再补一组 SVG，但通话头像涉及性别年龄匹配，emoji 的辨识度更高，建议先收反馈再动。
- SVG 形状现在是代码手绘的几何体（圆角矩形 + 圆弧），够干净但不是插画级精度；要更精致需引入位图或第三方图标集，与"零依赖 + `file://` 双击"冲突，属于需要单独决策的取舍。
