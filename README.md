# silver-care-memo · 岁岁念 —— 卡片式银发温情备忘录

Hack4Good「技术向善」参赛作品，由游戏设计开发背景与智慧养老企业实习背景的团队联合打造。

纯前端实现（HTML5 + CSS3 + 原生 JavaScript），**无需后端、无需安装任何依赖**，双击 `index.html` 即可在浏览器直接运行；所有卡片内容与打卡进度只保存在本机浏览器 `localStorage`。

## 30 秒体验路径（给评委）

1. 默认进入 **👵 长辈卡片模式**：左栏「今日概览」直接写着 *今天 4 件事 · 已办妥 0 件*；点一次 **把今天的事念给我听** 就能听完整轮今日备忘（再点一次即停），不用逐张点听一听。
2. 点卡片上的 **听一听** 听单张朗读，再点 **我办妥了** —— 红印章落下、撒花星星飘落、中文语音夸夸，概览的已办妥数与「连续坚持天数」同时跳一档；能量 +100，攒满 300 点亲情花园就从小嫩芽长成含苞待放。
3. 每次打卡都会点亮下方 **📅 打卡日历** 的当天；可翻看历史月份，按当天完成件数分三档深浅，今天描边高亮。
4. 想看成长曲线就点页脚 **补一段上周打卡（演示）**：一次性补出连续 4 天、能量 400、花园进第二阶段的完整状态（重复点击不会翻倍）。
5. 点左栏底部红色 **🚑 我不舒服**：紧急联系人、电话、住址、血型、正在服用的药、过敏史以大字摊在屏幕上，并可 **念给对方听**；切到子女模式同一个入口变成 **设置紧急求助信息**，模板化填空即可，不用打字。
6. 顶部一键切到 **🧑 子女守护模式**：选种类或直接用温情模板为父母新增卡片，已有卡片可随时 **修改**；上方「安心动态通知栏」实时同步父母刚完成的打卡与留言。
7. 点 **年度亲情战绩报告**：海报式年度总结 + 趣味勋章（如「全年按时吃药满贯王」「最佳暖心牵挂子女」），可 Ctrl / ⌘ + P 另存为 PDF 留念。
8. 页脚 **恢复示例数据** 可随时回到初始演示状态。

## 核心模块

| 模块 | 实现要点 |
| --- | --- |
| 适老化视觉与双端视角 | 米白底 `#FFFDF7` + 深色大字 `#222222`，基础字号 20px、标题 ≥30px、按钮高度 ≥60px、大圆角宽间距防误触；另提供 **标准 / 大 / 特大** 三档字号切换（记忆在本机） |
| 四类可视化大卡片 | 卡片统一白底，类别只以**左侧色条 + 类别标签**编码：💊 按时吃药（暖橙）、📞 亲友电话（天蓝，含模拟通话动画与振铃提示音）、🚌 出行提醒（翠绿）、💌 给孩子的留言（暖粉，大字短语一键发送），顶部大标签筛选 |
| 📋 今日概览 + 一键播报 | 长辈侧一眼看到"今天几件事 / 办完几件"，一个按钮顺序朗读全部未办卡片，中途可停；系统不支持语音时自动降级为文字提示，按钮状态同步回滚 |
| 📅 打卡日历 | 月视图（周一开头、可翻看历史月份、不可翻到未来），按当天完成件数分三档深浅，今日描边；实时统计当前连续打卡与最长记录，数据全部来自已有打卡记录 |
| 🔥 连续坚持天数 | 按打卡日期算出"最近一段没断的串"，**今天还没打卡就从昨天起算**（不在最需要鼓励的时段惩罚还没做的人）；与能量、花园阶段、年度战绩同源，不会互相矛盾 |
| 🚑 紧急求助信息卡 | 六个字段（联系人 / 电话 / 住址 / 血型 / 用药 / 过敏与既往）大字号摊开，电话按 3-4-4 分组、朗读逐位读汉字；子女侧填一次长期有效，长辈侧一键出示 |
| 🌱 亲情暖心花园 | 每次打卡能量 +100，四阶段成长（小嫩芽 → 含苞待放 → 繁花盛开 → 硕果累累）+ 粒子庆祝动画 |
| 语音朗读无障碍 | 浏览器原生 `speechSynthesis` 中文慢速朗读，三个入口：单张卡片的 **听一听**、左栏的 **把今天的事念给我听**（顺序念完全部未办卡片，中途可停）、紧急信息的 **念给对方听**；号码逐位读汉字，系统不支持时降级为文字提示并回滚按钮状态 |
| 🏆 年度亲情战绩回忆录 | 动态统计守护任务数、健康守护率、子女提醒次数、亲情能量与连续打卡，颁发趣味勋章并提供海报保存提示 |

## 隐私与细节

- 不联网、不上传任何个人信息；数据仅存于本机浏览器，换设备或清除站点数据即重置。
- 🚑 紧急求助信息（联系人 / 电话 / 住址 / 血型 / 用药 / 过敏与既往）是全应用唯一涉及真实个人健康信息的字段，同样**只写本机 `localStorage`**：不联网、不上传、长辈侧与子女侧读的是同一份本机数据；弹窗与页脚都写明这句声明，清除站点数据即彻底消失。子女侧编辑面板是六个带示例占位符的大输入框（电话用 `type="tel"`，手机上是数字键盘），填一次长期有效。
- 语音相关能力（单张听一听、一键播报今日、念紧急信息）全部走浏览器内置 `speechSynthesis`，**不需要联网**；系统不支持时降级为文字提示，且按钮状态当场回滚，不会出现"写着停下却什么都没念"。
- 视觉克制：卡片统一白底，类别只用左侧色条与标签色编码；页面静止时没有任何持续动画，撒花与音效只在「我办妥了」的瞬间出现。
- 一次性微动效：切换分类或视角时卡片错峰入场、亲情能量数字滚动到新值、花园跨阶段时植物回弹且阶段格子轻跳——都只在动作发生时播一次就停，重复打卡不会让整屏再跳一遍。
- 统一画风：类别图标、四阶段成长植物、操作按钮图标、紧急求助十字共 12 个符号，全部来自页面内的一份 SVG 精灵（跟随文字色自动反白，红底按钮上自然变白十字），不再混用系统 emoji；暖白底叠 5% 纸纹、阴影分两层，让干净的画面不至于寡淡。
- 跨日自动清空「已办妥」印章以便重新打卡（页面整天开着也会在跨日时自动重置），但能量与历史战绩累计保留。
- 支持键盘操作：首屏有跳转链接，弹窗内 Tab 焦点循环、关闭后焦点归还触发按钮；配色对比度按 WCAG AA 校验。
- 支持 `prefers-reduced-motion`，对动效敏感的长辈可关闭动画。
- 打开两个标签页（一个长辈模式、一个子女模式）可通过 `storage` 事件实时同步打卡动态。
