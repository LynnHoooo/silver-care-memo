# silver-care-memo · 岁岁念 —— 卡片式银发温情备忘录

Hack4Good「技术向善」参赛作品，由游戏设计开发背景与智慧养老企业实习背景的团队联合打造。

纯前端实现（HTML5 + CSS3 + 原生 JavaScript），**无需后端、无需安装任何依赖**，双击 `index.html` 即可在浏览器直接运行；所有卡片内容与打卡进度只保存在本机浏览器 `localStorage`。

## 30 秒体验路径（给评委）

1. 默认进入 **👵 长辈卡片模式**：点卡片上的 **🔊 听一听** 听语音朗读，再点 **✅ 我办妥了** —— 红印章落下、撒花星星飘落、中文语音夸夸，顶部亲情花园从 🌱 小嫩芽长成 🌷 含苞待放。
2. 顶部一键切到 **🧑 子女守护模式**：选种类或直接用温情模板（不用打字）为父母新增卡片，已有卡片可随时 **✏️ 修改**；上方「🔔 安心动态通知栏」实时同步父母刚完成的打卡与留言。
3. 点 **🏆 年度亲情战绩报告**：海报式年度总结 + 趣味勋章（如「全年按时吃药满贯王」「最佳暖心牵挂子女」），可 Ctrl / ⌘ + P 另存为 PDF 留念。
4. 页脚 **♻️ 恢复示例数据** 可随时回到初始演示状态。

## 五大模块

| 模块 | 实现要点 |
| --- | --- |
| 适老化视觉与双端视角 | 米白底 `#FFFDF7` + 深色大字 `#222222`，基础字号 20px、标题 ≥30px、按钮高度 ≥60px、大圆角宽间距防误触；另提供 **标准 / 大 / 特大** 三档字号切换（记忆在本机），正文与触控目标整体联动放大 |
| 四类可视化大卡片 | 💊 按时吃药（暖橙）、📞 亲友电话（天蓝，含模拟通话动画与振铃提示音）、🚌 出行提醒（翠绿）、💌 给孩子的留言（暖粉，大字短语一键发送），顶部大标签筛选 |
| 🌱 亲情暖心花园 | 每次打卡能量 +100，四阶段成长（小嫩芽 → 含苞待放 → 繁花盛开 → 硕果累累）+ 粒子庆祝动画 |
| 语音朗读无障碍 | 浏览器原生 `speechSynthesis` 中文慢速朗读分类、时间与具体内容，不支持时自动降级为文字提示 |
| 🏆 年度亲情战绩回忆录 | 动态统计守护任务数、健康守护率、子女提醒次数与亲情能量，颁发趣味勋章并提供海报保存提示 |

## 隐私与细节

- 不联网、不上传任何个人信息；数据仅存于本机浏览器，换设备或清除站点数据即重置。
- 跨日自动清空「已办妥」印章以便重新打卡（页面整天开着也会在跨日时自动重置），但能量与历史战绩累计保留。
- 支持键盘操作：首屏有跳转链接，弹窗内 Tab 焦点循环、关闭后焦点归还触发按钮；配色对比度按 WCAG AA 校验。
- 支持 `prefers-reduced-motion`，对动效敏感的长辈可关闭动画。
- 打开两个标签页（一个长辈模式、一个子女模式）可通过 `storage` 事件实时同步打卡动态。
